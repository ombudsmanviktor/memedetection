Carregando o modelo…

Como o app liga cada linha às imagens

  • Pelo nome do arquivo: uma coluna com 1234.jpg, imagens/1234.jpg ou vários nomes separados por |, como a coluna wgetlab_arquivo do manifesto do WgetLAB
  • Pelo ID: arquivos nomeados a partir de uma coluna de ID, no padrão do WgetLAB: <id>.jpg, <id>_1.jpg, <id>_2.png… Também vale o número da linha

A coluna mais provável é sugerida automaticamente. Quando uma linha tem várias imagens, ela é rotulada meme se pelo menos uma delas for meme. Formatos: JPG, PNG, GIF (primeiro quadro), WebP, HEIC, BMP e TIFF.

Sobre o modelo

Classificador meme × foto treinado por Matyáš Boháček com o Create ML (2020): extrator VisionFeaturePrint_Scene da Apple seguido de regressão logística, com 91% de acurácia de validação declarada pelo autor. Ele roda no Core ML do próprio macOS, por isso o app é só para Mac.

Configurar a análise

Confira a coluna que liga cada linha às imagens da pasta e, se quiser, ajuste o limiar e indique uma coluna com rótulos conhecidos para medir a acurácia.

1Coluna que liga linha e imagem
2Classificação
de 0,05 a 0,95 · padrão 0,5

Uma imagem vira meme quando a probabilidade calculada pelo modelo é maior ou igual ao limiar. Dá para mudar o limiar depois, na tela de resultados, sem analisar de novo.

3Avaliação da acurácia (opcional)

Se parte das linhas já foi codificada à mão, o app compara com o resultado do modelo e calcula acurácia, precisão, recall e F1. Valores aceitos: meme, 1, sim… para meme e foto, photo, 0, não… para foto. Células vazias são ignoradas.
